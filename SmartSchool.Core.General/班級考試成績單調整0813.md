# 班級考試成績單調整0813

## Todo 1 — 新增"即將下架報表"層級做法

### 需求說明
在成績相關報表下增加一層"即將下架報表"，讓班級考試成績單功能移至該層級下。

### 目標UI結構
```
班級統計報表
└── 報表 (buttonItem131)
    └── 成績相關報表 (buttonItem15)
        └── 即將下架報表 (buttonItem15_1)
            ├── 班級考試成績單 (buttonItem7) → Report0110
            └── 班級考試成績單(Word) (buttonItem3) → Report0120
```

### 實作做法

#### 1. 新增中間層節點
在現有的 `buttonItem15` 和具體按鈕之間，插入一個新的中間層節點：

```csharp
// 原本的結構
var buttonItem15 = buttonItem131["成績相關報表"];
var buttonItem7 = buttonItem15["班級考試成績單"];
var buttonItem3 = buttonItem15["班級考試成績單(Word)"];

// 修改後的結構
var buttonItem15 = buttonItem131["成績相關報表"];
var buttonItem15_1 = buttonItem15["即將下架報表"];  // 新增的中間層
var buttonItem7 = buttonItem15_1["班級考試成績單"];  // 改為從 buttonItem15_1 建立
var buttonItem3 = buttonItem15_1["班級考試成績單(Word)"];  // 改為從 buttonItem15_1 建立
```

#### 2. 具體實作步驟
1. **在 `Setup()` 方法中，在建立成績相關報表節點後，立即建立"即將下架報表"子節點**
2. **將原本直接從 `buttonItem15` 建立的按鈕，改為從新建立的 `buttonItem15_1` 建立**
3. **保持其他設定不變**（Click 事件、Enable 狀態、權限控制等）

#### 3. 程式碼變更點
- **新增行**：在 `var buttonItem15 = buttonItem131["成績相關報表"];` 後
- **修改行**：將 `buttonItem15["班級考試成績單"]` 改為 `buttonItem15_1["班級考試成績單"]`
- **修改行**：將 `buttonItem15["班級考試成績單(Word)"]` 改為 `buttonItem15_1["班級考試成績單(Word)"]`

#### 4. 注意事項
- 新增的中間層節點不需要 Click 事件綁定
- 新增的中間層節點不需要權限控制
- 只需要作為容器來組織子項目
- 保持原有的功能邏輯不變

## 備註
- 僅記錄，不修改程式
- 兩個控制項都位於 Setup() 方法中初始化，並在班級選取變更時透過 K12.Presentation.NLDPanels.Class.SelectedSourceChanged 事件控制報表按鈕的啟用狀態
- 兩個控制項都使用相同的權限檢查機制 (FeatureAccessControl.Executable())
- 兩個控制項都導向不同的科目選擇器對話框，但功能相似（一個是 Excel 版本，一個是 Word 版本）
- 兩個控制項都依賴於班級選取狀態，只有在選取班級時才能啟用報表功能
