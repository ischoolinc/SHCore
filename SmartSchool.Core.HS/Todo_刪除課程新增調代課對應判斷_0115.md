## Todo 1 — 修正 QueryData.cs：GetCourseDCBindCountByID
### 背景
目前 `GetCourseDCBindCountByID` 有 `string.Format` 未帶入參數等問題，可能導致 SQL 無法正確執行或結果不正確。

### 修改檔案
- 檔案：`QueryData.cs`
- 函式：`public static int GetCourseDCBindCountByID(string CousreID)`

### 修改規格
1. 必須正確將 `courseId` 帶入 SQL。
2. 避免 SQL 注入／型別錯誤：至少以 `int.TryParse` 驗證 `CousreID`。
3. 回傳規則建議：
   - `CousreID` 非整數 → 回傳 `0`（等同「無對應」）或依專案慣例回傳 `-1`（錯誤）；請擇一並在 log 記錄。
   - 正常查詢 → 回傳 count 值。
   - 例外 → 回傳 `-1`（保留原行為亦可）。

### 建議參考程式碼（可直接替換）
```csharp
public static int GetCourseDCBindCountByID(string CousreID)
{
    int value = -1;
    try
    {
        if (!int.TryParse(CousreID, out int courseId))
            return 0; // 或 return -1; 視專案錯誤策略

        QueryHelper qh = new QueryHelper();
        string strSQL = string.Format(@"
            SELECT count(id) AS count 
            FROM dc_bind_key 
            WHERE ref_course_id = {0};
        ", courseId);

        DataTable dt = qh.Select(strSQL);
        foreach (DataRow dr in dt.Rows)
        {
            int.TryParse(dr["count"].ToString(), out value);
            return value;
        }
    }
    catch (Exception ex)
    {
        Console.WriteLine("取得課程調代課對應筆數錯誤，" + ex.Message);
    }
    return value;
}
```

### 驗收
- [ ] 針對存在/不存在 dc_bind_key 對應的課程，回傳值正確（>0 / 0）。
- [ ] CousreID 非數字輸入時不拋例外（回傳符合規格）。

## Todo 2 — 修改 Manage.cs：刪除課程前加入「調代課對應」提示與確認
### 修改檔案
- 檔案：`Manage.cs`
- 函式：`private void btnDeleteCourse_Click(object sender, EventArgs e)`

### 插入位置
- 保留原本「修課學生人數」檢查邏輯（`attendCount > 0` 直接擋下刪除）。
- 在 `attendCount` 檢查通過後、進入原本的刪除確認 `MsgBox.Show("您確定將刪除此課程？"...` 之前插入。

### 行為規格
1. 呼叫 `GetCourseDCBindCountByID(deleteCourseID.ToString())` 取得筆數。
2. 若 `dcBindCount == 0`：直接進入原本刪除確認流程（不新增提示）。
3. 若 `dcBindCount > 0`：先顯示提示視窗（含筆數），詢問「是否仍要刪除」：
   - 使用者選 `No` → `return;`
   - 使用者選 `Yes` → 繼續進入原本刪除確認流程
4. 原本刪除確認視窗仍要保留（也就是可能會出現兩個確認：
   - 第一個：調代課對應提示（只有 dcBindCount>0 時出現）
   - 第二個：原本「您確定將刪除此課程？」確認）

### 建議插入程式碼
```csharp
// 取得調代課對應筆數
int dcBindCount = QueryData.GetCourseDCBindCountByID(deleteCourseID.ToString());

if (dcBindCount > 0)
{
    var dr = MsgBox.Show(
        string.Format("此課程尚有 {0} 筆調代課對應資料，若刪除課程可能造成調代課資料失效或不一致。\n是否仍要繼續刪除？", dcBindCount),
        "",
        MessageBoxButtons.YesNo
    );

    if (dr == DialogResult.No)
        return;
}
```

### 命名空間/引用注意
若編譯器找不到 `QueryData`：
- 方式 A：`Manage.cs` 加上 `using SmartSchool;`
- 方式 B：改成 `SmartSchool.QueryData.GetCourseDCBindCountByID(...)`

### 驗收（手動測試）
- 測試案例 A：`attendCount > 0`
  - [ ] 顯示「要刪除課程請先移除修課學生」並中止（不查 dcBindCount / 不顯示對應提示）。
- 測試案例 B：`attendCount == 0` 且 `dcBindCount == 0`
  - [ ] 只出現原本刪除確認（一次）。
- 測試案例 C：`attendCount == 0` 且 `dcBindCount > 0`
  - [ ] 先出現「調代課對應」提示（含筆數）。
  - [ ] 選 No：中止刪除。
  - [ ] 選 Yes：進入原本刪除確認。
- 測試案例 D：刪除成功後
  - [ ] 原本刪除後的事件/Log 寫入流程仍正常執行（無 Null、無例外）。
