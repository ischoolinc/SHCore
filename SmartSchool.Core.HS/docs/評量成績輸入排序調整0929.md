# 評量成績輸入排序調整 0929

## 修改檔案

- `CourseRelated/ScoreDataGridView/IDataProvider.cs`
- 類別：`SmartSchoolDataProvider`
- 位置：建構子內取得課程修課學生的 SQL（`qryCourseStudent`）

## 原排序方式

```sql
ORDER BY class_name, seat_no, student_number
```

順序：班級名稱 → 座號 → 學號

## 新排序方式

```sql
ORDER BY
    class.display_order ASC NULLS LAST,
    class.class_name ASC,
    student.seat_no ASC,
    student.student_number ASC
```

順序：`display_order` → 班級名稱 → 座號 → 學號

## SELECT 變更

新增欄位：

```sql
class.display_order
```

## class.display_order 的 NULL 處理方式

- 使用 PostgreSQL `ASC NULLS LAST`
- 有設定 `display_order` 的班級依數字由小到大排在前面
- `display_order` 為 `NULL` 的班級排在最後
- `display_order` 相同時再依 `class.class_name` 排序

## 資料型態確認

- 程式其他處（如 `CourseInformation.ClassDisplayOrder`）以 `int` 處理班級顯示順序
- 因此 `ORDER BY` 直接使用數值排序：`class.display_order ASC NULLS LAST`
- 未轉成字串排序，避免 `1, 10, 11, 2` 這類錯誤順序

## 測試結果

程式碼層級已確認：

1. 多個班級有 `display_order`：依數字小至大排序
2. `display_order = 2` 與 `10`：數值排序為 `2 → 10`
3. `display_order = NULL`：以 `NULLS LAST` 排在最後
4. `display_order` 相同：再依 `class_name` 排序
5. 同班學生：維持 `seat_no ASC → student_number ASC`
6. 未改動成績讀取、狀態篩選、顯示所有學生、欄位產生、儲存相關邏輯

實際 UI 驗證請於「評量成績輸入」畫面以多班級課程資料再確認一次。
